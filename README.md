# Java alkalmazások – Beadandó (Spring Boot, Java 25)

Futtatás: `mvn clean package` majd `java -jar target/beadando.jar`
(a kész JAR-t másoljátok a repo főmappájába `beadando.jar` néven)

Oanda adatok: állítsátok be az `OANDA_TOKEN` és `OANDA_ACCOUNT` környezeti változót,
vagy írjátok be a `hu.beadando.Config` osztályba (publikus repóba ne commitoljátok a tokent!).
